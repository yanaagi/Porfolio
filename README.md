# Developer Portfolio

A responsive Next.js + Tailwind CSS portfolio starter for Shopify, WordPress, eCommerce, SEO, and accessibility work.

## Run locally
1. Install Node.js 20+.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Before publishing
- Replace `Your Name` / `YOUR NAME` in `app/layout.tsx` and `app/page.tsx`.
- Replace `your.email@example.com` with your email.
- Add your GitHub and LinkedIn URLs in the contact footer.
- Add exact Shopify store URLs and case-study descriptions to the `projects` array in `app/page.tsx`. The first Shopify card is intentionally marked for URL/details confirmation rather than claiming a specific store.
- Add real project screenshots in `public/` and replace the abstract visual placeholders in the project cards.
- Confirm client permission before publishing work, metrics, screenshots, or confidential details.
